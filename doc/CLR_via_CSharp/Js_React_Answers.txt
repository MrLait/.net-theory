# Перерисовка компонента
Перерисовка компанента будет тогода когда меняется propps либо стэйт или просто передан объект, который не меняется(меняется ссылка)

Перерисовка компонента обернутого в React.memo будет лишь в том случае если изменился хотябы одни из пропсов либо если в самом компаненте изменился стэйт. Но важно
что у примитивных типов сравнение по значению а у обхектов по ссылке.

useMemo ситоит использовать практичестки во всех случаях кода работаете с объектами, массивами, вычислениями, которые возвращают значение https://www.youtube.com/watch?v=zPrliWeyfkA&list=PL6DxKON1uLOHya4bDIynPTCwZHrezUlFs&index=16&ab_channel=UlbiTV
при работе с примитивным типом данных usememo не нужен

useCalback ситоит использовать если передаем функцию в дочерний компанент
useRef может помчоь, чтобы не прокидывать в зависимости пропсы для useCalback, если работаем с useState https://www.youtube.com/watch?v=F8EvdTsl6hU&list=PL0FGkDGJQjJH4Uz-Vsk_91V65Wh88nlXC&index=5&ab_channel=ArchakovBlog
